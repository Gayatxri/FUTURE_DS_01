# Social Media Campaign Performance Dashboard

## Project Overview
This Power BI dashboard analyzes social media ad campaign performance
using metrics such as impressions, clicks, conversions, and ad spend.

## KPIs Included
- Total Impressions
- Total Clicks
- Total Conversions
- Approved Conversions
- Total Spend

## Tools Used
- Power BI
- Excel / CSV Dataset

## Key Insights
- Campaign performance varies significantly across campaigns
- Impressions trend shows peak engagement during mid-campaign period
- Certain age and gender segments perform better
