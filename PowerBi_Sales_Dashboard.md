# 📊 Power BI Sales Dashboard

## 📌 Project Overview
This project analyzes sales performance using the Superstore dataset.
The dashboard provides insights into sales trends, profit, orders, category and regional performance.

## 🛠 Tools Used
- Power BI
- Superstore Dataset
- Data Modeling & Visualization

## 📈 Key Insights
- Total Sales: 2.30M
- Total Profit: 286.40K
- Technology category generates the highest sales
- Sales peak during the last quarter of the year
